# LeetCode 709 - To Lower Case

## Problem

Given a string `s`, convert all uppercase letters in the string to lowercase letters and return the resulting string.

## Approach

Use Python's built-in `lower()` method to convert the entire string to lowercase.

```python id="0k9m5k"
return s.lower()
```

## Python Concepts Used

* **String methods** – Use the built-in `lower()` method.
* **String manipulation** – Convert characters to lowercase.
* **Return statement** – Return the transformed string directly.

## Time Complexity

**O(n)** — Each character in the string is processed to create the lowercase string.

## Space Complexity

**O(n)** — A new lowercase string is created.

## Key Learning

Python provides built-in string methods such as **`lower()`** that simplify common string transformation operations.
