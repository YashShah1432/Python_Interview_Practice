# LeetCode 2235 - Add Two Integers

## Problem

Given two integers `num1` and `num2`, return their sum.

## Approach

The problem can be solved directly using the `+` arithmetic operator.

```python
return num1 + num2
```

The two input values are added together and the result is returned.

For example:

```text
num1 = 12
num2 = 5

12 + 5 = 17
```

Therefore, the output is:

```text
17
```

## Python Concepts Used

* Class and method
* Function parameters
* Arithmetic operator (`+`)
* `return` statement

## Time Complexity

**O(1)**

Only one arithmetic operation is performed.

## Space Complexity

**O(1)**

No additional data structures are used.
